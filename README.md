# Архив Аудио и Фото

Веб-приложение для архивирования и воспроизведения аудио и фото с Яндекс.Диска.

## Структура проекта

```
/workspace
├── index.html      # Главная страница
├── style.css       # Стили
├── app.js          # Основной JavaScript
├── sw.js           # Service Worker для кэширования
├── manifest.json   # PWA манифест
├── api.php         # PHP API для управления данными
└── README.md       # Этот файл
```

## Возможности

### Для пользователей:
- 🎵 Просмотр и воспроизведение аудио треков
- 📷 Просмотр фото (бета-версия, заглушки)
- ⬇️ Скачивание файлов
- 💾 Кэширование для офлайн-доступа
- 📱 Адаптивный дизайн для мобильных устройств

### Для администраторов:
- ➕ Добавление аудио треков через публичный ключ Яндекс.Диска
- ➕ Добавление фото через публичный ключ Яндекс.Диска
- 🗑️ Удаление контента
- 📋 Управление списком файлов

## Установка на хостинг

1. Загрузите все файлы на ваш PHP хостинг
2. Убедитесь, что у сервера есть права на запись в директорию (для создания data.json)
3. Откройте сайт в браузере

## Использование API

### Получить список всех данных
```
GET /api.php?action=list
```

### Добавить аудио трек
```
POST /api.php?action=add_audio
Content-Type: application/json

{
  "name": "Название трека",
  "key": "https://yadi.sk/d/ВАШ_КЛЮЧ"
}
```

### Добавить фото
```
POST /api.php?action=add_photo
Content-Type: application/json

{
  "name": "Название фото",
  "key": "https://yadi.sk/d/ВАШ_КЛЮЧ"
}
```

### Удалить аудио трек
```
POST /api.php?action=delete_audio&id=ID
```

### Удалить фото
```
POST /api.php?action=delete_photo&id=ID
```

## Как получить публичный ключ Яндекс.Диска

1. Откройте файл или папку на Яндекс.Диске
2. Нажмите "Поделиться" → "Скопировать ссылку"
3. Ссылка будет вида: `https://yadi.sk/d/XXXXXXXXXXXXXX`
4. Используйте эту ссылку как `public_key`

## Интеграция с Яндекс.Диск API

Приложение использует API Яндекс.Диска для получения прямых ссылок на файлы:

```
GET https://cloud-api.yandex.net/v1/disk/public/resources?public_key=<ВАШ_КЛЮЧ>
```

Ответ содержит поле `file` - прямую ссылку для воспроизведения/скачивания.

## PWA (Progressive Web App)

Приложение поддерживает PWA функции:
- Установка на домашний экран мобильного устройства
- Офлайн-работа (кэширование ресурсов)
- Автономный режим отображения

Для установки на Android:
1. Откройте сайт в Chrome
2. Нажмите меню (три точки) → "Установить приложение"

## Подготовка к сборке APK

Для конвертации в Android приложение используйте:

### Вариант 1: WebView приложение
Создайте Android проект с WebView, который загружает ваш сайт.

### Вариант 2: TWA (Trusted Web Activity)
Используйте Bubblewrap или аналогичные инструменты для создания TWA.

### Вариант 3: Capacitor/Cordova
```bash
npm install -g @capacitor/cli @capacitor/core
npx cap init
npx cap add android
npx cap sync
```

## Хранение данных

По умолчанию данные хранятся в:
- **localStorage** (клиентская сторона) - для быстрой работы
- **data.json** (серверная сторона) - для постоянного хранения через PHP API
